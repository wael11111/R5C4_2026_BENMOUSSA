# R5C4 - Données décisionnelles

## Description

API développée en Python avec Flask dans le cadre du module R5C4.

## Architecture

Le projet utilise une architecture en couches :

- Controller
- Service
- Repository
- DTO

## Séance 1

- Mise en place du projet Flask
- Configuration de l'environnement virtuel
- Mise en place de SQLite
- Création du Repository
- Création du Service
- Création du DTO
- Création du Controller
- Première route `GET /api/v1/parties`
- Mise en place de la pagination `limit` / `offset`
